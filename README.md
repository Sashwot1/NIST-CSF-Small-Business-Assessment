# NIST CSF 2.0 Small-Business Cybersecurity Assessment

## Project Overview

This is an independent cybersecurity portfolio project based on a fictional small textile manufacturing company.

I created the project to practice identifying business assets, evaluating cybersecurity risks, assessing security gaps, and recommending realistic improvements using the NIST Cybersecurity Framework 2.0.

The fictional organization has 15 employees and relies on Windows computers, Microsoft 365, online banking, cloud file storage, spreadsheets, and a small wireless network.

## What I Completed

For this project, I:

- Defined the fictional company's operations and technology environment
- Created an inventory of eight business assets
- Identified and evaluated seven cybersecurity risks
- Used a simplified likelihood and impact model to prioritize risks
- Mapped findings to relevant NIST CSF 2.0 categories
- Compared the company's current and target cybersecurity posture
- Developed practical priority actions
- Created a 90-day cybersecurity improvement plan

## Key Findings

The main risks identified were:

- Microsoft 365 accounts without multi-factor authentication
- Shared accounts and reused passwords
- Inconsistent and untested backups
- Irregular system patching
- Limited phishing-awareness training
- No documented incident-response plan
- Unmanaged removable media

## Methodology Note

The risks were scored using a simplified likelihood and impact model created for this portfolio project. It is not an official NIST scoring methodology.

No vulnerability scanning, penetration testing, log analysis, interviews, or technical control testing was performed.

## Disclaimer

Everest Loom Textile Manufacturing is a fictional organization created for educational purposes.

This project did not involve the systems, employees, customers, financial information, records, or confidential data of any real company.
